SAR TRACKER — SETTINGS
==================================================================

MOST SETTINGS NOW LIVE IN  ->  config.js

Open config.js, change a value, save, hard-refresh the browser
(Ctrl+Shift+R). The page reads that file directly — no build step.
Every setting there is commented with its allowed choices, and a bad
value is ignored (with an explanation in the browser console, F12)
rather than breaking the page.

config.js covers: map view, theme, font size, language, time zone,
starting filters, product-type defaults, all colours, statistics
panel defaults, and chart appearance defaults.

This file now only documents the two areas config.js does NOT cover,
because they are read before the page runs or by a separate program.

==================================================================


[A] DATA FETCHING                                      fetch_sar_data.py
------------------------------------------------------------------
Controls what gets DOWNLOADED, not what gets displayed. Runs as a
separate Python program, so it has its own settings.

Entries marked [env] need no file edit — set the variable when you
run the script:
    DAYS_BACK=14 python fetch_sar_data.py

  :57                           limit a rebuild to one mission
  choices: all | sentinel1 | nisar
  example: REBUILD_SCOPE=nisar python fetch_sar_data.py
