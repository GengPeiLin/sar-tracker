# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

SAR Tracker is a static single-page dashboard (no build step, no npm) that displays Taiwan SAR satellite acquisition frames on a Leaflet map. It is deployed as a GitHub Pages site directly from the `main` branch.

**Stack:** plain HTML + vanilla JS + CSS. No framework, no bundler, no package.json. Leaflet 1.9.4 loaded from unpkg CDN.

## Development

Open `index.html` directly in a browser (`file://`) or serve it locally:

```bash
python -m http.server 8080
# then open http://localhost:8080
```

No build, lint, or test commands exist. Changes are live-reloaded by refreshing the browser. Deploy = `git push origin main` (GitHub Pages auto-deploys).

When running locally via `file://`, data is loaded from `data/sar_status.js` (a `window.__SAR_DATA = {...}` assignment). On the web, data loads from `data/sar_recent.json` first (last 14 days, fast), then upgrades to `data/sar_status.json` in the background with a progress bar.

## Architecture

Everything lives in three files:

| File | Purpose |
|------|---------|
| `index.html` | Static shell: header, sidebar, map container, stats panel, mobile nav. No dynamic content. |
| `app.js` | All application logic (~3 000 lines). Sections are delimited by `// ═══` banners. |
| `styles.css` | All styles (~2 100 lines). Three responsive breakpoints: default (desktop), `≤980px` (tablet), `≤640px` (mobile). |

`data/sar_status.js` and `data/sar_status.json` / `sar_recent.json` are generated by an automated update script and committed daily; do not hand-edit them.

### `app.js` section map (top → bottom)

1. **`SATS` array** — static satellite catalogue (id, band, agency, status, `asf_prefix[]`, bilingual descriptions)
2. **`TRANSLATIONS`** — all UI strings in `en` and `zh-TW`; accessed via `t(key, vars)`
3. **Global constants** — `FEATURED_SATELLITES`, `OPEN_DATA_SATELLITES`, `PLATFORM_COLORS`, `NISAR_TRACK_COLORS`, `APP_VERSION`
4. **`state` object** — single mutable app state; `ensureAdvancedState()` lazily adds filter sub-keys
5. **Data loading** — `loadData()` / `applyFrameData()` / `reconcileFrameMetadata()` / `enhanceFrame()`
6. **Map** — Leaflet init, polygon rendering, selection, highlight styles, drawer open/close
7. **Sidebar & filters** — satellite list, band/tab chips, advanced filters (date, track, frame, product type, direction)
8. **Download / export** — URL copy, CSV export, export panel
9. **Stats panel** — `statsState`, `openStatsPanel` / `closeStatsPanel`, `renderStatsPanel`, `buildStatsPanelHTML`, `buildStatsTableHTML`, `renderStatsChart`, `buildChartBuckets`, `buildFrequencyStats`, export helpers
10. **`DOMContentLoaded`** — wires up all event listeners, calls `loadData()`

### Key patterns

**Re-render pattern:** Controls (chips, selects, buttons) call a state-mutation function that ends with `renderStatsPanel()`. `renderStatsPanel` saves `body.scrollTop`, replaces `body.innerHTML` with freshly-built HTML, restores scroll, then re-renders the SVG chart in a `requestAnimationFrame`. Because innerHTML replacement detaches nodes before bubbling completes, the document-level click-outside handler uses `event.composedPath().includes(statsPanel)` — not `contains()`.

**i18n:** All UI text goes through `t(key)`. Add keys to both `en` and `zh-TW` blocks in `TRANSLATIONS`. `data-i18n="key"` attributes on static HTML are updated by `applyI18n()`.

**Frame data shape** (post-`enhanceFrame`): `satellite_id`, `platform`, `date` (ISO string), `path_number_norm` (integer track), `direction_norm` (`ASCENDING`/`DESCENDING`), `frame_number_norm`, `is_open_data`, `track_label` (`A69`, `D105`, `OTHER_S1`, `NISAR`, …)

**Taiwan Sentinel-1 tracks:** T69 (ASC), T105 (DESC), T142 (ASC), T171 (DESC). Constants `STATS_S1_IDS` and `STATS_S1_TRACKS` in `app.js` are the authoritative list. The stats chart defaults to showing only T69 and T105 (`statsState.activeTracks`).

**Stacking contexts:** `header` z-index 200, stats panel fixed z-index 600, `.map-wrap` uses `isolation: isolate` so internal z-index values (map overlays at 1100–1200) don't escape into the page stacking context.

**Mobile layout (≤640px):** `.hdr-controls` is hidden; `.sidebar` and `.map-wrap` are `position: absolute; inset: 0` within a `position: relative` `.layout`. Navigation is the bottom `.mob-nav` tab bar (z-index 800). The stats panel has `bottom: 52px` to sit above the tab bar.
